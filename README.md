## №2 Проектирование класса

### Класс Student

Класс `Student` предназначен для представления информации о студенте и управления его состоянием.

| Элемент | Описание |
|---|---|
| **Имя класса** | `Student` — класс, представляющий студента |
| **Поля** | `name` — имя студента; `age` — возраст; `averageGrade` — средний балл; `course` — курс обучения; `group` — учебная группа типа `StudyGroup`; `objectCount` — статический счётчик существующих объектов |
| **Конструкторы** | `Student()` — конструктор без параметров; `Student(name, age, averageGrade, course, group)` — параметризованный конструктор; `Student(other)` — конструктор копирования |
| **Методы чтения** | `getName()` — получение имени; `getAge()` — получение возраста; `getAverageGrade()` — получение среднего балла; `getCourse()` — получение курса; `getGroup()` — получение учебной группы; `getObjectCount()` — получение количества существующих объектов |
| **Методы изменения** | `addGrade(grade)` — добавление оценки; `advanceCourse()` — перевод студента на следующий курс; `changeGroup(newGroup)` — изменение учебной группы |
| **Инварианты** | Возраст должен находиться в диапазоне от 16 до 100 лет; средний балл — от 0 до 5; курс — от 1 до 6; название учебной группы не должно быть пустым, номер группы должен быть положительным. Некорректные значения не должны изменять состояние объекта. |
